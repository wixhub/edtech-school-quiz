# EdTech School Quiz Platform

An interactive learning and quiz tool designed for digital schools and educational support.

## Tech Stack

- **Backend:** Python, Flask, Flask-CORS

- **Frontend:** Angular, TypeScript (Signals, Standalone Architecture)

## Project Structure

- `/backend` - Python REST API server (Flask-based, teacher-friendly JSON storage, secure anti-cheat validation)

- `/frontend` - Modern Angular web user interface tailored for children and teenagers (responsive mobile-first design)

## Collaboration & Customization

Collaborations, custom implementations and integrations are welcome. Should there be a need to adapt this platform for educational institutions—whether through localization into other languages or scaling the functionality with bespoke features—assistance and consultations are available upon request.

For inquiries, feature requests or custom adaptations, please open an [Issue](../../issues) or start a discussion in the [Discussions](../../discussions) tab.
